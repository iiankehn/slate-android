# Slate product brief

## Positioning

Slate by CORE is one writing space for quick notes, longer drafts, and complete documents. It should open quickly, save continuously, and remain understandable without tutorials or an account.

## First public version

The R1 implementation now covers this baseline. R2 remains a separate full word-processing product rather than an incremental R1 version.

- Create, edit, duplicate, rename, pin, archive, and delete documents.
- Headings, paragraphs, bold, italic, underline, links, lists, checklists, and quotes.
- Folders, tags, favorites, and full-text search.
- Images and simple tables.
- Undo/redo and local version history.
- Import and export plain text, Markdown, and DOCX.
- Export and print PDF.
- Android share-sheet support.
- Phone, tablet, foldable, keyboard, mouse, touch, and stylus-aware interaction.

## Explicitly later

- Optional encrypted multi-device sync.
- Real-time collaboration.
- Comments and tracked changes.
- Desktop-class pagination and advanced page layout.
- Templates and automation.

## Non-goals

- Advertising or engagement features.
- A mandatory CORE account.
- Cloud-only files.
- Microsoft Word feature parity in the first release.
- Proprietary formats that trap a user's writing.
