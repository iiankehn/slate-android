# Slate — October 2026

This release unifies Slate Notes and Slate Forge into one private, local-first Android writing app. A new document begins as a lightweight note and preserves the complete Forge document model automatically when you add page-layout features. There is one library, one editor, and one release line.

## Highlights

- One adaptive workspace for quick notes, letters, reports, résumés, and longer documents.
- Structure-aware Note and Forge classification without using document length as a shortcut.
- Rich text, headings, quotes, links, lists, checklists, tables, images, undo, redo, and keyboard shortcuts.
- Page setup, sections, margins, orientation, columns, headers, footers, page breaks, and paginated editing.
- A polished Material 3 interface with automatic Android light and dark themes, including a theme-aware editing canvas.
- A quieter branded start center featuring Slate's cat-fox artwork, focused creation actions, templates, search, filters, favorites, archive, and trash.
- A collapsible phone formatting ribbon and a dedicated compact landscape layout that preserves writing space above the software keyboard.
- Responsive tablet, large-window, keyboard, mouse, and Googlebook Android foundations.

## Files and interoperability

- `.slx` provides a portable rich-note format shared across Slate workflows.
- `.slxf` preserves Slate's complete Forge page and layout model.
- Import support includes `.slx`, `.slxf`, TXT, Markdown, and DOCX.
- Export support includes `.slx`, `.slxf`, TXT, Markdown, DOCX, and PDF, with Android share and print integration.

Exporting a Forge document as `.slx` may simplify page-specific features in the exported copy. Slate does not modify the original document during export.

## Local-first by design

- No account, advertising, analytics, telemetry, or background update polling.
- Documents remain in app-private storage until you explicitly import, export, print, or share.
- Screenshot and recent-app preview capture remain blocked while Slate is visible.
- Automatic Android cloud backup and broad storage access remain disabled.
- Manual updates use the official GitHub release, SHA-256 verification, and Android package-signature enforcement.

## Upgrading and migration

Existing Slate Notes users can install the signed APK over the current official installation. Slate keeps the same package and signing identity and migrates the local library in place. Do not uninstall first; uninstalling removes app-private documents.

The former standalone Slate Forge package used a different Android identity. Export its documents as `.slxf` or `.slx`, then import them into this unified Slate application.

## Requirements and current limitations

- Android 12 or newer.
- ARM64 and x86_64-compatible Android environments.
- Advanced DOCX features may simplify during import or export.
- PDF output uses Slate's own page rendering rather than full print-press typography.
- Cloud synchronization and real-time collaboration are not included.
- Encrypted whole-library backup, guided standalone-Forge migration, and additional large-document performance work remain planned.

Please report reproducible bugs through [GitHub Issues](https://github.com/iiankehn/slate-android/issues/new/choose). Remove private writing and sensitive documents before attaching diagnostic material.
