# Slate — November 2026

This release adds encrypted whole-library backup, fuller library organization, and version history, and gives text-only notes a continuous writing canvas.

## Upgrading

- Install over Slate October 2026 or use **Check for updates**; your documents remain in place.
- Slate versions now read `year.month.revision`, starting with `2026.11.1`.
- Do not uninstall to update. Uninstalling removes app-private documents.

## Highlights

- **Encrypted library backup.** Save the whole library to a password-protected `.slatebackup` file and restore it later with a preview and a choice to keep both copies, replace existing documents, or keep the newer version.
- **Library organization.** Edit folders and tags from the start center, filter by them, and save frequent text searches.
- **Version history.** Preview earlier checkpoints of a document and restore one as a new edit.
- **Continuous note canvas.** Text-only notes use a single continuous writing surface with formatted text, lists, and image controls.
- **Safer editing around embedded objects.** Paragraph edits keep their cursor positions aligned and no longer drop embedded objects when text is replaced.
- **Recovery fixes.** Pending edits and restored content are preserved across interrupted saves and restarts.

## Opening files

- Files opened from other apps and files chosen in Slate now share one import path, with the same size limits and the same messages.
- Oversized files are rejected before they are fully read into memory, and a file Slate cannot open shows an error instead of being ignored.
- When a file provider hides the file extension, Slate uses the reported file type to recognise `.slx`, `.slxf`, Markdown, DOCX, and text files.
- Rotating the device right after opening a file no longer imports it a second time.

## Current limitations

- Saved searches stay on this device and are not included in library backups.
- Guided migration from the former standalone Slate Forge app is still planned; export `.slxf` or `.slx` from Forge and import those files.
- Advanced DOCX features may be simplified on import or export.
- Cloud synchronization and real-time collaboration are not included.

Please report reproducible bugs through [GitHub Issues](https://github.com/iiankehn/slate-android/issues/new/choose). Remove private writing and sensitive documents before attaching anything.
